# Akış: Web — Rehberlik

Format: [flows/_format.md](_format.md). Kaynak: PDF §16 (rehberlik paneli), §17
(erken uyarı mantığı).

Kapsanması gereken alanlar (PDF §16):
- Öğrenci profili (merkezde) — deneme sonuçları, çalışma süresi, soru sayısı, ödev
  durumu, etüt, telefon kullanımı, günlük bildirimler, rehberlik görüşmeleri
- Zaman serisi görünümü — "bugünkü durum" değil "geçmişten bugüne nasıl değişti"
  (PDF §3, §17)
- Rehberlik notu ekleme/görüntüleme
- Yalnızca yetkili olduğu öğrencileri görme kısıtı (RBAC, PDF §30)

**Not:** İlk sürümde otomatik kırmızı/sarı/yeşil risk sistemi zorunlu değil (PDF §16)
— bu ekranlarda "ham veri + zaman serisi" yeterli, otomatik skorlama Faz 4'e ait.

> **Doldurulmadı.** Ekran ekran doldurulacak.
