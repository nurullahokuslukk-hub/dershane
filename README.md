# Dershane

İsteğe bağlı Android uygulama kullanım süreleri → tenant izolasyonlu API → sunucu tarafında kategori eşleme → atanmış rehberliğin web paneli.

Geliştirme sürümüdür. KVKK/veli-temsil süreçleri, PostgreSQL üretim entegrasyonu, gerçek Android cihaz testleri ve Play Store yayını henüz tamamlanmamıştır. Gerçek öğrenci verisi kullanmayın.
